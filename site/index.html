rimor

Latin: I probe, I search thoroughly.

A terminal workbench for PostgreSQL, SQL Server and SQLite. Browse the catalog, write SQL in tabs and scroll through millions of rows without leaving the keyboard.

go install rimor.dev/cmd/rimor@latest

What it does

Explorer
Your connections and their catalog as a tree: databases, schemas, tables, views, functions, indexes and columns with their types. Each level loads when you open it, and empty schemas stay out of the way.
Query tabs
Each tab knows where it runs, a connection and a database, and shows it at the bottom. Open a tab from anything in the tree and it starts there. Tabs save to .sql files, and unsaved work is still there the next time you start.
Results
Rows appear within milliseconds and keep streaming in the background, stored compactly enough for millions of them. Scroll by row and by column; esc stops fetching and keeps what arrived.
Errors
The database's own message and code, with the failing line of your SQL and a caret where the database points.
Editor
Syntax highlighting in each database's own dialect, selection, undo, clipboard and indentation that follows the line above.
Sessions
Every tab runs on its own connection, so USE, temp tables and open transactions carry over from one run to the next.
Themes
Dark, light, or your terminal's own colours. On Omarchy rimor follows the system theme; elsewhere it matches your terminal's background.
Layout and keys
Drag the borders between panes, or resize from the keyboard; any pane goes full screen with alt+f. Every shortcut can be remapped, and ctrl+g lists them all.

Install

With Go

A single binary with no other dependencies, for Linux, macOS and Windows. Needs Go 1.27 or newer.

$ go install rimor.dev/cmd/rimor@latest
$ rimor

From source

Clone the repository and build the command; the binary lands in the current folder.

$ git clone https://github.com/alchemy/rimor
$ cd rimor && go build ./cmd/rimor

Press a in the explorer to add a connection. Settings live in ~/.config/rimor/config.toml, written with every default on first run.
